# antislop audit 001, 2026-09-15

Scope: `output/accommodation.html`, `output/room-ocean-hill-suite.html`, `output/room-garden-view-pool-villa.html`, `output/room-ocean-view-pool-villa.html`, plus `css/pages/accommodation.css`, `css/pages/room-detail.css` and the shared components they use.
Mode: 2 (after). Direction: `design.md` exists and was used as the reference. No file was modified.

Design Read: room listing and room detail for leisure travellers booking a hilltop resort, in a calm editorial photo-led language; dials inferred from `design.md` as ENERGY 1 / RHYTHM 2 / MOTION 2 (the file does not declare them, see finding 17).

Evidence run (puppeteer-core + system Chrome, static server over `output/`):
- No horizontal overflow at 375 / 768 / 1024 / 1440 on all four pages.
- Room tabs: Suites shows 1 chapter, Pool Villas shows 2, All shows 3.
- Lightbox: opens from the overview frame, closes on Escape, on all three room pages.
- Console: no script errors; one 404 on accommodation.html (favicon, see finding 18).
- Local link targets missing: `blog.html`, `id/<page>.html` (see findings 2 and 3).

Priority: HIGH = Hard Gate rule, MEDIUM = Purpose-Gate rule, LOW = Quality Lock or liveliness note.

## Findings

### HIGH (Hard Gate)

1. **R-02 em dash in visible copy.** `accommodation.html:152, 179, 206` (each chapter text), `room-garden-view-pool-villa.html:157` (room description), and the `<title>` of all four pages. Rule forbids the character in any text. Replace with comma, period or colon.

2. **R-24 nav link to a page that does not exist.** Mobile menu "Blog" and footer "Blog & Articles" point to `blog.html`, which is not in `output/`. Present on all four pages (site-wide component). Remove the item or label it "Coming soon".

3. **R-24 language switcher and hreflang point to a missing mirror.** `id/accommodation.html`, `id/room-*.html` do not exist in the static build; the EN/ID switcher (header, mobile menu, footer) is a dead control until Polylang renders it. Acceptable only if the WordPress build ships the mirror; in the static deliverable, hide the ID link or mark it inactive.

4. **R-38 room photos reused from other rooms and labelled as this room.** Ocean Hill Suite gallery shows `Lobby.jpeg`, `Pool.jpeg` and `hero_resort_*.jpeg` under "Inside the Ocean Hill Suite"; Garden View Pool Villa gallery uses `one-bedroom-ocean-view.jpg` (the suite photo) captioned as villa interior; Ocean View Pool Villa uses `one-bedroom-ocean-view.jpg` and `villa-room.jpg`. The HTML comment admits the assumption, but the visitor sees it as final. Either use the room's own photos, or show the existing `empty-state` ("Photos coming soon") for the strip and gallery until the client set arrives.

5. **R-03 tap target below 44px.** Header "Book Now" pill measures 121x40 at every breakpoint (token `--control-min-sm` 40px). Rule minimum is 44px. Card and chapter title links are inline text (41px / 27px) and pass as text links, but the header pill is a button-styled control.

6. **R-25 contrast over the hero photo is unverified.** Breadcrumb links render at `rgb(255 255 255 / 70%)` at 12px uppercase, tagline at 85% white, over a photo whose scrim is only 20% black through the middle band (`.page-hero__scrim`). On a bright sky region this can fall under 4.5:1. Measure on the actual photos (`Villa.jpeg`, `one-bedroom-ocean-view.jpg`, `villa-room.jpg`, `two-bedrooom-family-pool.jpg`) or raise the scrim behind the content block.

### MEDIUM (Purpose-Gate)

7. **R-10 glass dose exceeded on the listing.** Header on scroll (blur 8px) + six `.chapter__badge` pills (blur 4px) + lightbox backdrop (blur 6px) on one page. `design.md` documents the "glass pill" value but not why badges over photos need blur. Drop the `backdrop-filter` from `.chapter__badge` and `.tag`; the 92% opaque fill already reads.

8. **R-26 "Inquire" carries parameters nothing reads.** `contact.html?subject=reservation&room=ocean-hill-suite#inquiry` navigates correctly, but `contact.js` never reads `location.search`; the subject select stays on "Choose a topic" and the room is lost. Either prefill the form from the query, or drop the parameters and link to `contact.html#inquiry`.

9. **R-08 arrow on two buttons, none on the rest.** Room detail panel "Book Now ↗" and "All Rooms →" carry arrows; the other eight buttons on the same page do not. ↗ for "opens STAAH in a new tab" is a real cue; keep it on every external Book Now or on none. "→" on "All Rooms" is decoration.

10. **R-04 icon set chosen without a written reason, and one icon per amenity row.** `design.md` 3.7 says "Lucide" but not why the thin-stroke set fits a warm editorial resort. The amenity list puts a Lucide glyph on all 17 rows (`i-frame` for a mirror, `i-wind` for air conditioning, `i-shirt` for a wardrobe), which is icon-as-bullet. Keep icons on the four spec values (they carry meaning next to a number) and render amenities as a plain two-column list.

11. **C-3 same photo shown three times on one room page.** The hero, the overview frame and the first gallery tile all use the room's single photo; the two-image `detail__strip` repeats two of the five gallery tiles. Merge the strip into the gallery, or make the gallery the only photo section below the overview.

12. **R-05 room detail runs three "section-head + grid" blocks in a row.** Amenities, Gallery and Other Rooms all use kicker + title + grid, then the info band, then CTA. With RHYTHM 2 the page should break once: for example, put the amenities list beside the overview panel or run the gallery full-bleed.

### LOW (Quality Locks and liveliness)

13. **C-1 room facts repeated three times.** Listing chapter: badge "Ocean View" + subtitle "Suite · 41 sqm" + spec grid "View: Ocean View / Size: 41 sqm". Detail panel: tags "16 Rooms / Ocean View" + kicker "Suite · 16 Rooms" + spec grid. Choose one carrier per fact.

14. **R-16 brochure filler in descriptions.** "thoughtfully designed", "elegantly appointed", "exclusive accommodations", "peaceful sanctuary for guests seeking relaxation". The intro is already marked `TODO(content)` lorem; the room descriptions read the same way. Replace with specifics (balcony depth, pool size, what you see at sunrise).

15. **R-15 bare CTA "Inquire".** Compare "Talk to us on WhatsApp" on the same page. Suggest "Ask about this suite" / "Ask about this villa".

16. **One accent on five element types per chapter.** Gold on kicker, tagline, spec icons, breadcrumb separator, gold button, plus hairline rules. `design.md` says "quiet gold accents"; on the listing every chapter has six gold touches. Drop gold from spec icons (use `--color-soft`) so the tagline and button keep it.

17. **Dials not declared.** `design.md` describes mood and motion but never sets ENERGY / RHYTHM / MOTION. Add one line (suggested: `Dial: ENERGY 1 / RHYTHM 2 / MOTION 2`) so the section rhythm and reveal density in finding 12 and 19 are checkable.

18. **Missing favicon.** One 404 per page load. Add `<link rel="icon">`.

19. **R-19 reveal on every block.** `data-reveal` sits on the section head, each chapter media and body, each of the four info items, the note and the CTA. Matches MOTION 2, and the stagger is documented, but the note and CTA band gain nothing from rising. Limit reveal to chapters, grids and section heads.

20. **Footer "Hotel Information" column carries unconfirmed figures.** "5 Stars · 41 Rooms", "Nusa Penida Harbor · 5 km" are from the deck with a `TODO(content)` comment. Not fabricated (deck is the source), but confirm with the client before launch or the R-17 gate fails at delivery.
