## Bukti pengujian (setelah perbaikan)

puppeteer-core + Chrome sistem, server statis di atas `output/`:
- Tidak ada overflow horizontal di 375 / 768 / 1024 / 1440 / 1920.
- Console: hanya 404 favicon (terbuka). Error `pattern` hilang.
- Submit kosong → 6 error tampil, fokus ke nama. Telepon berisi huruf → error telepon tampil. Check-in lampau → error tampil. Form valid → "Sending…" + `aria-busy`, lalu status sukses menerima fokus, form di-reset.
- Menu mobile → toggle membuka, Escape menutup (`aria-expanded` false).
- Hero meta: tiga tautan `tel:` / `wa.me` / `mailto:`, tinggi 44px.
- Float WhatsApp: parked saat `#inquiry` terlihat, tampil lagi di `#directions`; tidak menutupi tombol CTA di 375.
- Tabel jarak: keenam `dd` rata kanan di 375.
- Target sentuh di bawah 44px di 375: hanya checkbox persetujuan (18px, area sentuh = label) dan input honeypot tersembunyi.
- Tautan lokal tanpa tujuan: `privacy-policy.html`, `blog.html`, `id/contact.html` (semua terbuka, menunggu klien).
- Screenshot ditinjau di 1440 dan 375: hero, seksi inquiry, peta, directions, CTA, footer.
